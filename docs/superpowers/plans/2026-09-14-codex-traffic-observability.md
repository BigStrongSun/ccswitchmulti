# Codex 路由状态/流量页面改造计划

用户明确指定现有“状态→流量”页面落地。范围为被动用量可观测性第一期，不运行对照实验，不改模型路由，不把跨来源用量相加。
基线：216f870e；隔离分支bigstrongsun/codex-traffic-observability，保留主树protocol_compatibility.rs未提交更改。

## 执行步骤
1. 后端Terra：定位get_codex_subagent_usage_stats，先红测复现范围外agents混入今日统计、无usage被当零；校正范围计数与缺失标记，复用已有分项token。限制历史扫描、区分采样与全量，保持代理与本地会话独立来源；父子关系没有实证不造树。
2. 前端Terra：在CodexRouterWorkspacePage.tsx原入口抽取流量组件；呈现输入/缓存/输出及请求耗时、覆盖率/缺失；无证据显示未采集。自动刷新仅在可见/激活页且使用有界已有查询，不自动同步全部历史。保留手动同步。组件测试先红后绿。
3. 主agent：审查数值口径、累计差分、时间范围、缓存去重及采样边界；运行整合typecheck与focused tests；本地浏览器真实渲染截图检查，fixtures仅证明UI，不冒充真实账单。
4. 更新本仓库memory，详细本地commit；源码、测试、构建、安装与运行态分别报告。没有安装验收不声称截图所在已运行程序已更新；不擅自中断当前Codex依赖的CCSM代理。

## 验收
- 仍在状态/流量入口，两路数据来源与不可相加边界明显。
- 时间范围外session不进入本期已观测数；未采集不显示0美元当实际费用。
- 分项token不重复相加，缓存子集标识清晰。
- 页面切走/隐藏不持续触发重型同步；刷新失效与手动同步状态可见。
- regressions/types/格式/UTF8通过；有bounds和known limitations说明。

## 证据边界
内置web与Matrix独立检索均已尝试；内置无可读返回，Matrix搜索返回第三方参考不作为技术依据。技术实现以本地源码、回归测试和官方文档正文为依据，不虚构双链验证成功。
