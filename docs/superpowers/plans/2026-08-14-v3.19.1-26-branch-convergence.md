# CCSwitchMulti v3.19.1-26 Branch Convergence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不可变的 `v3.19.1-25` 基线上汇总缺失的 Provider/MultiRouter 改进，完成全历史 refs 功能分叉审计，并发布可安装、可回滚、可验证的 `3.19.1-26`。

**Architecture:** 使用隔离 worktree 和选择性提交移植，不合并旧分叉整树。候选先经过 ancestry、patch-equivalence、当前树语义和测试四级判定，再按 RED/GREEN 边界进入 release 分支；历史分叉结论形成持久审计文档。

**Tech Stack:** Git worktree/cherry/patch-id、React 18、TypeScript、Vitest、Rust/Tauri、Cargo、Pester、PowerShell、GitHub Actions/Release。

## Global Constraints

- 基线固定为 `v3.19.1-25^{}` / `4d19b80a0c0f077de3968d3f12271924c6825a97`。
- 不移动、删除或复用 `v3.19.1-25` 标签。
- 不采用 `bigstrongsun/fix-portable-third-party-reasoning` 的整体历史合并。
- 保留 Sub-Agent V1/V2、V2 profiles、事务安装器、更新器、历史配置与后端路由兼容层。
- 中间提交使用空 `core.hooksPath`；每个提交正文最后一段为 `本次提交由BigStrongsSun完成`。
- 前端全集必须使用 `--exclude '**/.worktrees/**' --no-file-parallelism`。
- 安装必须由单一独立事务进程完成 kill、卸载、安装、启动、健康验证和失败回滚。
