# CCSwitchMulti v3.19.2-22

本版本修复 Codex Desktop 新版在部分任务中报 `FeatureToml in features.guardianv2`、导致任务无法继续的问题。

## 主要改进

- 修正 Renderer 兼容层的 Statsig 动态配置作用域：模型白名单变换只应用于模型白名单配置，不再污染 Guardian V2 或其它功能配置。
- 启动时可识别并清理由旧版 CCSM V5 兼容层加入的三个模型字段，同时保留 Guardian 的启用状态和其它未知字段。
- 仅当 app-server 明确返回 Guardian V2 的 `FeatureToml` 结构错误时，把当前请求中的 Guardian 对象降级为布尔值并重试一次；网络错误、其它功能配置及原始请求不受影响。
- 兼容层升级为 V6，请求补丁升级为 V5，可在 Codex 无需重写磁盘 TOML 的情况下修复已经运行的 Renderer。

## 根因说明

旧版 CCSM 把模型目录白名单字段写入了每一个 Statsig 动态配置。Codex Desktop 随后会把 Guardian 动态配置映射成请求级 `features.guardianv2`；新版 app-server 对该对象执行严格结构校验，因此拒绝包含 `available_models`、`default_model`、`use_hidden_models` 的污染对象。报错文案虽然写着无法加载 `config.toml`，但现场磁盘 TOML 并不包含该键，真正错误来自请求内覆盖。

## 验证基线

- Renderer 兼容层定向测试：31 条通过。
- Rust library：3769 条通过，0 条失败，6 条显式忽略。
- `cargo check --lib --no-default-features`、rustfmt、diff 和 UTF-8/no-BOM 检查通过。
- 真实 Codex Renderer canary 在保留故障输入的情况下成功恢复受影响任务，没有再次出现 Guardian V2 `FeatureToml` 错误。

安装包与安装后二进制仍需以本版本干净构建导出的 SHA-256、可回滚替换事务和安装态 Renderer 标记验收结果为准。
