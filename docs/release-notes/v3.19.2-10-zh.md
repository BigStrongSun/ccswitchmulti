# CCSwitchMulti v3.19.2-10

这是一次面向第三方 hosted 工具链的兼容性和诊断修复版本。

## 修复

- 修复第三方 MultiRouter 路由把入站 `Bearer PROXY_MANAGED` 或第三方 Bearer 错当成 ChatGPT OAuth，导致官方 hosted `web_search` 请求认证失败的问题。
- 只有官方 native Codex 路由允许复用入站真实 Codex OAuth；第三方路由会回退到 CCSwitchMulti 托管的 Codex OAuth，或使用显式 hosted-tool API key。

## 诊断能力

- 当请求显式要求 `web_search` 或 `generate_image`，而上游返回成功响应却没有发起 hosted function call 时，新增脱敏日志事件 `hosted_tool_not_called`。
- MultiRouter 的 Debug 检查会明确提示：工具已经投影给上游，下一步应检查模型或网关是否支持 OpenAI-compatible function calling。
- 普通 `tool_choice=auto` 下模型自然选择不搜索不会被误报。
- 诊断不记录 prompt、工具 schema、响应正文或凭据，也不会根据 prompt 猜搜索词或伪造工具调用。

## Qwen/vLLM 边界

Qwen3.8 的真实 canary 已证明 CCSwitchMulti 能把 `web_search` 投影到 Chat Completions 请求，但当前部署仍没有产生 function call。该部分属于 Qwen/vLLM 上游能力或配置边界，本版本不会在代理层强行接管模型决策。
