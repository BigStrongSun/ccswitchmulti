# CCSwitchMulti v3.19.2-15

## 修复

- 修复 MultiRouter V2 路由的 `matchPrefixes` 未被所有运行时匹配入口识别的问题。此前保存新格式路由后，部分第三方模型可能回退到首个官方路由。
- V2 `modelSelection.mode = "include"` 的模型现在参与精确匹配；`matchPrefixes` 参与前缀匹配。兼容旧格式 `match.models`、`match.prefixes` 和 `modelPrefixes`。
- 路由匹配规则已统一用于真实请求转发、Sub-Agent/provider 分类、模型目录投影、`/v1/models` 展示与升级期路由修复。因此适用于所有 V2 Provider，不限于 DeepSeek 或 GLM。

## 验证

- Rust 回归覆盖 V2 DeepSeek 前缀与 include 模型在官方 fallback 前命中目标 route。
- `cargo check`、定向 Rust 单测和本机事务安装后运行态验证通过。
