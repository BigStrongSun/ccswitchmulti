# CCSwitchMulti v3.20.2-20

本版修复四个用户报告的问题：MFJS 工具 schema 422（#87/#101）、Codex App 跨线程消息毒化第三方会话（#98）、设置页"应用界面加载失败"（env injection 空状态）、以及严格诊断版 Codex Desktop 的 `unrecognized configuration settings` 警告。另合并社区贡献：Responses 重复 namespace 整合（#95）、原生图片编辑官方回退路由（#97）、MiMo 2.6 Chat 工具调用适配（#103）、Codex 插件登记安全修复（#69）与 Rust 依赖组更新（#90）。

## 修复

### 1. MFJS 工具级 fail-open 与 Moonshot 端点门控（#87、#101）

**问题**：第三方路由（含 DeepSeek）的 `/v1/responses` 请求因 Codex 动态工具 schema（非互斥 `oneOf`、`encrypted` 未知键等）触发 Moonshot MFJS 编译失败，整请求 422。

**根因**：① MFJS 方言旧契约为整请求 fail-closed，单个不可表示工具毒化整个请求；② 探针把"模型行为偏差"误判为"上游 schema 拒绝"，把 `moonshot_mfjs` 方言持久化到非 Moonshot 路由档案，运行时再无条件继承。

**修复**：
- 工具级 fail-open：不可表示的单个工具只丢弃该工具并记录日志，请求继续；非互斥 `oneOf` 放宽为 `anyOf` 并降级该工具为 `strict=false`；未知 schema 键丢弃并降级非严格。
- MFJS 切换/继承双门控：仅 Moonshot/Kimi 端点且证据为显式/模糊 schema 拒绝时生效；非 Moonshot 路由的旧档案不再触发 MFJS。
- 空参数/无效参数的工具调用不再是 schema 拒绝证据，改为同方言 `tool_choice=required` 静默重试一次。

### 2. Codex App 跨线程消息毒化第三方会话（#98）

**问题**：`send_message_to_thread` / `automation_update` 向目标 thread 注入的 standalone synthetic `function_call_output`（`namespace=codex_app`、无 `call_id`）被转换为 `tool_call_id` 缺失的 tool 消息，导致该 session 后续所有请求（含 `/compact`）永久 422，每收一次跨线程消息就重新污染。

**修复**：Provider-facing Responses→Chat 转换层将此类孤儿合成事件投影为普通 user 消息（保留完整 output 内容）；其他命名空间的孤儿工具结果与正常配对工具历史保持严格 fail-closed 校验。升级后受影响 session 下次请求自动恢复。

### 3. 设置页"应用界面加载失败"（ROG AMD v3.20.2-19）

**问题**：`envInjection.enabled=true` 且变量为空时打开设置页，整屏被 React 错误边界替换为"应用界面加载失败"，重载死循环。

**根因**：`EnvInjectionTargetSyncStatus` 6 个 Vec 字段带 `skip_serializing_if`，空数组被省略；前端类型声明其必选 → `undefined.map` TypeError。

**修复**：移除 6 个 `skip_serializing_if`（保留 `serde(default)` 兼容旧负载），补 Rust 序列化与前端空 wire-shape 回归测试。

### 4. 严格诊断版 Codex Desktop `unrecognized configuration settings` 警告

**问题**：新版 Codex Desktop（≥26.912）对 `model_providers.<id>.models` 内联投影报未识别配置警告。

**修复**：按 Desktop 包版本门控（只信 26.MDD 体系）：≥26.912 停写内联 models 并清理旧版本残留，只保留顶层 `model_catalog_json`；旧版与探测失败维持旧行为（零回归）。

## 社区贡献（本次合入）

- **#95**：Responses 请求中重复的 `tool_search` namespace 声明按网关契约整合（仅对已确认拒绝重复声明的网关生效），修复 `Duplicate namespace name 'mcp__...'`。
- **#97**：原生 Codex 图片编辑（`POST /v1/images/edits`）走与图片生成一致的官方回退路由解析；multipart 仅读取路由字段，不重建上传内容。
- **#103**：MiMo 2.6 Pro/Flash Chat 工具调用适配：FREEFORM `apply_patch` 原始补丁归一化、目录与请求参数口径对齐。
- **#69**：Codex 缓存插件登记安全修复：检测个人 marketplace 缺失的已启用缓存插件并显式修复，保留既有条目。
- **#90**：Rust 依赖组 58 项更新。其中 3 项破坏性 major 升级本版回退旧版本（沿用 #14 拆批先例）：`rusqlite 0.40`（移除 `u64`/`usize` SQL 转换，涉及约 30 处数据库写读边界）、`toml 1.0`/`toml_edit 0.25`（`Value::FromStr` 不再解析文档，破坏全量 provider 配置解析链，曾导致 200+ 测试失败）；其余 55 项保留，并对 `sha2 0.11`（hybrid-array 摘要 hex 编码）、`hmac 0.13`（`KeyInit` 导入）、`tokio-tungstenite 0.30`/`axum 0.8`（`Utf8Bytes` 转换、通配路由 `/{*name}` 语法、移除 `Option` 提取器）做了行为等价小适配。

- CI：`actions/cache` 5 → 6（#5）。
