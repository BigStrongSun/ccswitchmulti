# CCSwitchMulti v3.19.1-3

## 修复内容

- 应用内更新器会复用 CCSwitchMulti 已配置的全局 HTTP/SOCKS 代理，避免模型转发可用、而更新器直连 GitHub 超时。
- 数据库恢复页、应用标题、设置页和托盘入口统一打开 CCSwitchMulti 的仓库或发布页，不再跳回原版 CC Switch 页面。
- 保留 Tauri 签名校验、下载进度和 Windows 安装前清理流程；更新失败时仍可从 Multi 发布页手动安装。
