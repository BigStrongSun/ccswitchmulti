# CCSwitchMulti v3.20.2-9

This release fixes missing reasoning presentation for third-party models in Codex Desktop and binds automatic conversion to protocol-probe evidence.

## Codex Desktop reasoning mapping

- Trusted local `Codex Desktop` requests enable the adapter automatically; there is no separate UI toggle.
- The Chat path projects readable raw reasoning such as `reasoning_content`, `reasoning`, `reasoning_details`, and think tags only from a verified Chat probe profile.
- The native Responses path uses the Responses probe profile for the final provider, public model, and upstream model to map `response.reasoning_text.delta/done` into the summary lifecycle that Desktop renders.
- Mapping is enabled only for a current, unexpired, `Verified` profile with `selected_transport=open_ai_responses` and a readable raw reasoning shape. Existing summaries, opaque/no-reasoning responses, and missing or failed probes remain unchanged.
- If an upstream sends a reasoning delta before `response.output_item.added`, CCSM completes the reasoning item and summary-part lifecycle automatically.

## Compatibility and safety boundaries

- CLI, TUI, External API, and non-Desktop requests retain their original reasoning semantics.
- The adapter is generic: it does not special-case DeepSeek, GLM, or hostnames; model differences come from probe profiles.
- The currently running older CCSM process is not terminated or replaced by this source release operation.
