# CCSwitchMulti v3.19.2-13

这是一次 MultiRouter 目录投影可见性和旧路由诊断修复版本。

## 修复

- 工作台状态页现在会显示 MultiRouter Provider/模型目录投影是否已同步。
- 投影过期、缺失、回读不一致或发布失败时，界面显示后端错误码和原因，并提供
  「重新同步目录」入口；重同步成功后直接刷新当前投影状态。
- 当前有效映射会显示可读的 Provider 名称、可见模型和上游模型，不再把
  `router-UUID` 作为用户可见路由名称；原始 ID 仅保留在诊断元数据中。
- 保留 visible model 与 upstream model alias 的统一身份解析，不改变既有路由行为。

## 验证

- Codex Router workspace 定向测试：61 passed / 0 failed。
- `codex_multirouter` Rust 定向测试：56 passed / 0 failed。
- TypeScript 类型检查和 Prettier 检查通过。
- 发布后安装态还需独立核验版本、hash、监听端口、`/health`、`/v1/models`，
  以及旧 UUID route/catalog canary。
