# CCSwitchMulti v3.19.2-13

> 本版本是 **v3.19.2-13 的同版本重发**。旧的 3.19.2-13 发布对象已从
> `BigStrongSun/ccswitchmulti` 撤下；本次 tag、安装包和 updater manifest 必须重新
> 指向本次最终提交，不能把旧的同版本安装包当作本次修复。

这是一次 MultiRouter 目录投影、路由可见性和 Codex Sub-Agent 能力来源链的修复版本。

## 修复

- 工作台状态页显示 MultiRouter Provider/模型目录投影是否已同步；投影过期、缺失、
  回读不一致或发布失败时，显示后端错误码和原因，并提供重新同步入口。
- 当前有效映射显示可读的 Provider 名称、可见模型和上游模型，不再把
  `router-UUID` 作为用户可见路由名称；原始 ID 只保留在诊断元数据中。
- 保留 visible model 与 upstream model alias 的统一身份解析，不改变既有路由行为。
- Sub-Agent 输入能力采用统一且可解释的来源优先级：
  **profile 显式配置 > route 能力 > model catalog 显式声明 > 内置模型名注册表**。
  状态面板逐项显示每个来源、当前采用项和冲突，避免把 route/name 推导结果伪装成
  catalog 声明。
- 修复了模型能力来源冲突时的实际采用值与界面展示不一致问题，并补充 profile、
  route、catalog 冲突回归测试。
- 官方模型的速度档和推理档改为动态跟随本机 Codex 自带官方目录：
  `models_cache` backup 缺失或为空时，自动读取 `codex debug models --bundled`
  并按 slug 覆盖最新官方 metadata；新发布模型无需在 CCSM 中维护模型名单。

## 分支审计边界

- 本次发布基于当前 `main`，已核对历史功能分支和开放 PR；排序、停用模型、
  usage provider 名称、Ultra、Responses-Lite、unsupported-tools、DeepSeek
  catalog 等功能在主线已有等价或更完整实现，不整枝重复合入。
- AgentMesh 原型、实验分支和资料型 Sub-Agent 分支仍不属于本版本的生产运行时，
  不纳入发布包。
