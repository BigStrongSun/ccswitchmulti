# CCSwitchMulti v3.19.1-16

本版本在 fork 分支 `fix/preserve-user-extras` 上发布，修复开机自启 bug：设置"开机自动启动"后重启系统，应用未随登录自动启动。

## 用户可见修复

### 1. 设置开机自启后重启不再失效

- 修复设置"开机自动启动"后，重启系统应用未自动启动的问题。
- 根因：auto-launch 0.5.0 的 Windows 实现有两处缺陷——
  1. 写 Run 注册表值时路径不加引号，安装在含空格路径（如 Program Files）时登录按空格截断，启动失败；
  2. 关闭自启时只删 Run 值、不清除 StartupApproved 覆盖项，残留假启用状态。
- 修复：Windows 分支绕过 auto-launch crate，直接用 winreg 操作注册表——
  - 开启：写引号包裹的 exe 路径，并同步写 StartupApproved enabled 标记；
  - 关闭：删除 Run 值与 StartupApproved 覆盖项，消除假状态；
  - 状态查询：严格校验 Run 值等于当前 exe 路径，避免残留旧路径误报。
- 对应提交：`dbfe6273`。

## 升级与验收

1. 完全退出 CCSwitchMulti（含托盘图标）。
2. 覆盖安装 `CCSwitchMulti_3.19.1-16_x64-setup.exe`（或 fork release 对应安装包）。
3. 在设置中开启"开机自动启动"，重启系统，确认 CCSwitchMulti 随登录自动启动。
4. 到设置中关闭再开启自启，确认状态正确同步，无残留假启用。
