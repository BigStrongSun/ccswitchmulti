# CCSwitchMulti v3.20.4-11

修复智谱 GLM 官方模型详情页元数据补齐：兼容当前 Markdown 模型卡片格式，并可读取上下文窗口、最大输出 Tokens 与输入/输出模态。仅补齐模型列表未提供的字段，不覆盖接口显式返回值。

模型列表解析同时覆盖常见供应商扩展：DeepSeek 的 OpenAI `data[]` 元数据、阿里云百炼/Qwen 的 `output.models[].model_info` 与 `inference_metadata`、vLLM 的 `max_model_len`，以及 Strata 的 `meta.n_ctx` 和 `architecture` 模态字段。只解析有明确语义的正整数/模态值；缺失或无效时保持未知。供应商响应中的任意字段并不都会被 CCSM 持久化，当前只投影模型选择与能力展示所需的字段。

跨平台安装包、签名及自动更新清单由 GitHub Release workflow 构建和验收；具体平台覆盖以发布产物为准。
