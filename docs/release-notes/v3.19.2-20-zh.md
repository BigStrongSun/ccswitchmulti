# CCSwitchMulti v3.19.2-20

本版本集中收口 Codex Provider 自动协议适配、配置生效检查、历史恢复和 Windows 运行时替换流程。

## 主要改进

- 恢复完整的 Codex MultiRouter 引导流程，并保留页面导航与真实工作流状态的边界。
- 将 Responses 与 Chat 兼容证据按 Provider、模型和协议独立保存；自动混合协议使用隐藏叶子，普通列表只显示逻辑 Provider。
- 协议深探测复用生产请求策略，覆盖认证、模型映射、User-Agent、Header/Body override、流式、推理、工具调用与续轮。
- Codex 自己维护的桌面、MCP、插件、项目信任等 TOML 字段不再触发 CCSM 配置漂移；只有 CCSM 管理投影发生变化才要求刷新。
- 修复超长任务因重复 ordinal 导致分页历史停滞的问题；只处理可证明安全的相邻重复序列，并保留原文件备份。
- 修复当前 Codex Desktop renderer 更新后历史兼容层无法找到真实请求客户端的问题。
- 将“配置与运行态”“分页历史”“界面历史查询兼容层”拆成三个独立结果；界面兼容层失败不再覆盖前两项成功状态，并可单独重试。
- Codex Provider 工具栏新增常驻“Codex 状态与修复”入口，关闭和重新打开 Codex 前仍需明确确认。
- Windows 强制关闭只逐个结束身份已重新核验的进程，不再递归结束子进程；本地升级使用带备份、回滚、端口和健康校验的事务。
- 受控升级在停止旧实例后会按 PID、归一化路径、版本和进程启动时间精确退役旧运行 marker，不再把成功替换误报成 CCSM 异常退出；身份不一致时安装失败关闭并保留原 marker。
