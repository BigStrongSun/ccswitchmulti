# CCSwitchMulti v3.20.4-12

补齐 Codex Provider 的维护型推理强度能力库：

- 增加 DeepSeek V4 Flash 官方模型项。
- 增加阿里云百炼 Qwen 3.8 Max、Flash、2.4T、27B 系列推理档位和默认值。
- 增加百炼 GLM 5.3、5.2、5.2 Fast Preview、5.1、5 的模型级配置，并区分可关闭思考与强制思考型号。
- 增加智谱直连 GLM 5.3、5.3 Flash、5.2 配置，按智谱 API 档位独立映射。
- 按官方 API 主机识别百炼与智谱 Provider；自建网关不会只因模型名称相同而套用官方维护项。用户在 CCSM 中手工填写的模型能力仍优先。

配置依据来自 DeepSeek、阿里云百炼及 Z.AI 官方 API 文档；模型列表与档位仅覆盖文档明确说明的精确模型 ID。
