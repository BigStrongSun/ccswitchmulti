# CCSwitchMulti v3.20.2-4

这是 `v3.20.2-3` 的定向修订版，修复 Codex“状态与修复”刷新过程不可观测、任务卡死后前端仍显示进行中的问题。数据库 schema 继续保持 v22。

## Codex 状态与修复

- 刷新进度不再只有阶段名：关闭进程、等待退出、分页历史扫描/迁移/逐文件修复、配置重投影、启动和验证都会显示具体日志。
- 长操作每 2 秒发送一次心跳；界面新增修复进度日志、最后活动时间和当前阶段已等待时间。
- 分页历史修复增加 15 分钟硬超时，底层文件或 SQLite 卡住时不再让命令永久挂起。
- 前端新增 30 秒无事件看门狗；后端事件链静默会明确失败，不再一直显示“正在刷新”。
- 每次刷新使用独立 run id，迟到的后端结果不会覆盖已经判定为卡死的失败状态；事件序号和时间戳会丢弃乱序/重复事件。

## 验证

- 后端 heartbeat、分页历史进度、前端日志渲染、事件收集、静默看门狗和迟到结果忽略均有 TDD 回归。
- 前端全量 189 files / 1566 tests 通过；Rust 串行全量 4113 passed / 0 failed / 7 ignored；typecheck、Prettier、rustfmt、cargo check 通过。
