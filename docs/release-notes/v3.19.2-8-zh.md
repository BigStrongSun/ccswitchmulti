# CCSwitchMulti v3.19.2-8

本版本合并 Codex MultiRouter、Codex Desktop 兼容性和模型能力链路的一组修复与增强。

## 修复

- 修复 macOS Codex Desktop 部分 `/v1/responses` 请求缺少稳定 `User-Agent` 时，被误判为 External OpenAI API、无法进入 MultiRouter 的问题。
- 修复官方 Codex 路由的 Desktop OAuth 透传边界，兼容旧版官方 route 配置，同时保留托管 OAuth、账号池和显式外部 API 的鉴权隔离。
- 修复 HTTP-only Codex 配置仍被 WebSocket 探针误报失败的问题；`supports_websockets=false` 时诊断会正确检查 HTTP Responses 路径。
- 修复流式 Responses 在上游截断时缺少 `response.incomplete` 的协议收尾问题。
- 修复 hosted tools、函数工具与 Chat/Responses 转换中的混合工具边界，避免不支持的工具被静默丢弃或错误串行化。
- 修复 Codex 历史回放中外部加密内容污染模型切换和后续请求的问题。
- 修复 Qwen/vLLM 默认输出上下文配置被错误写入通用 CCSM 配置的问题。

## 新增与增强

- 新增 Codex 模型推理能力目录和统一能力解析链，支持支持/不支持/未知三态、来源追踪、能力指纹、默认值和 UI 展示。
- 增强 Codex Sub-Agent V2：模型目录跟随 MultiRouter、不可路由模型保守剪枝、推理能力未知时阻止可路由 profile 保存，并提供只读检测和检查接口。
- 增强 hosted web_search、生图和工具调用的 Responses 流式状态机，改善第三方模型在 streaming auto 场景下的兼容性。
- 增强 Codex Debug 诊断：`codex-router.log` 新增 `request_classified` 事件，记录请求是否包含 User-Agent、是否识别到 Codex、是否带外部 API key、是否有强制外部标记以及最终分类路径；不记录 Token、Cookie、Authorization 原文或请求体。
- 补充 Mac 与 Windows Codex Desktop 运行差异的排障信息，帮助区分入站请求分类、OAuth 准备和上游网络发送阶段。

## 升级提示

- 启用 Codex takeover 后，建议完整退出并重新打开 Codex Desktop，使新的 provider 和模型目录生效。
- 发生问题时优先查看 `~/.cc-switch/logs/codex-router.log`：`request_classified` 表示请求已到达本地入口，`route_resolved` 表示已完成路由，`upstream_send_error` 表示失败发生在 CCSM 到真实上游的发送阶段。
- 本版本的诊断日志只保存脱敏布尔字段和路径摘要，不保存凭据或请求正文。
