# CCSwitchMulti v3.19.0-4

## 修复内容

- Codex MultiRouter 自环与假成功根修：retry 候选在进入账号池/重试前先物化真实目标 Provider；最终有效上游指向 CCSM 当前监听端口时在网络发送前失败，不再递归 15721，也不再记成成功。
- 账号池运行态：按 credential generation 约束 session affinity，支持 24 小时 TTL 与 2048 LRU；统一 success/credential/quota/transient/neutral 结果分类；账号级 401/403/402/429/瞬时失败切换下一账号，不污染 Router 持久健康。
- 停止 Codex 对 in-flight Responses 超时的整轮自动重发：可能已在途的 send/header/body 超时映射为 429 + Retry-After，托管的 Codex provider 设置 request/stream max retries=0。
- 修复 Codex 历史扫描阻塞 CCSM UI：子 Agent 用量统计改为 async/spawn_blocking，只对零 token 子 Agent 回退 rollout；新增 rollout metadata mtime/TTL 缓存与强制重扫。
- 修复重命名会话标题被历史修复回滚：SQLite 显式标题优先，列表、详情、重建和 recent-window 更新统一保留用户重命名。
- 修复 MSI 构建 ICE38：per-user sidecar 组件改用 HKCU RegistryValue KeyPath。
- 新增 Codex hosted web_search 桥接：第三方 Chat 上游收到普通 function tool，forwarder 内有界执行 OpenAI hosted web_search 并把结果回灌；原始 stream 请求会正确包装为最小 response.completed SSE。
- 保留 v3.19 上游能力：Desktop 登录门面、OAuth 账号池去重、原生 Responses/Chat 兼容、模型目录同步、历史恢复等。
