# CCSwitchMulti v3.19.2-16

## 新增

- **DeepSeek V4 Flash Vision 实验模型目录**：内置 `deepseek-v4-flash-vision-exp`，上下文 1048576，输入支持文本与图像，推理强度 low/high/max（默认 high），支持关闭 thinking 与 original 图片细节。后端不再把 DeepSeek V4 全家族误判为纯文本模型，旧配置缺少 reasoning 元数据时会恢复内置能力声明。
- **模型输入能力可编辑**：Codex Provider 的“模型目录明细”支持 `文本与图像` / `仅文本` 分段选择，并可从 CCSM 预设一键恢复；覆盖写入当前 Provider 的 `settings_config.modelCatalog.models[]`，不需要修改全局内置 preset。
- **Codex Ultra 独立解锁**：Ultra 从能力来源映射中拆出，作为 Codex V2 的独立档位；自动发现能力时也会呈现 Ultra，用户可单独解锁并配置映射，不会随 automatic/manual 覆盖被混淆。

## 修复

- 生成模型目录时，用户显式声明的图像能力现在覆盖文本模型兜底，避免“目录显示多模态但后端仍按纯文本处理”的残留状态。

## 验证

- `pnpm typecheck` 通过。
- Vitest 覆盖模型目录、自动发现、Ultra 与输入能力编辑的定向回归通过。
- Rust 覆盖 DeepSeek V4 精确文本判定、reasoning 恢复与显式图像能力覆盖的定向回归通过。
