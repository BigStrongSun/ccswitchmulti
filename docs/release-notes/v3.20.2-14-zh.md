# CCSwitchMulti v3.20.2-14

设置页新增“看门狗与端口自检”面板，把守护状态和端口占用现场直接显示出来，不用再翻日志。

## 新增

- **守护进程状态**：是否启用、当前守护 PID、是否仍在运行（未运行会标红）。
- **最近 30 分钟自动拉起次数**：来自守护的重启预算记录。
- **本地代理端口**：端口、当前监听 PID、是否就绪（监听者不是本安装态程序时标为异常）。
- **端口占用诊断**：只有异常时才展开，直接给出 TCP 表里的 PID、状态与“身份不可读”的原因。
- **最近事件**：守护日志最新的 8 条（`supervisor-started` / `supervisor-restarted` / `supervisor-clean-exit` …）。
- 面板右上角可手动刷新；数据来自只读命令 `get_watchdog_status`，不会改动任何运行状态。

## 验证

- 后端新增 `recent_events` / `last_supervisor_pid` / `recent_restart_count`，含单元测试 `supervisor_log_round_trip_finds_events_and_last_pid`。
- 前端新增 `WatchdogStatusPanel`（含 2 条组件测试：健康态与异常态），设置页接入。
