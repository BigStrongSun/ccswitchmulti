# CCSwitchMulti v3.20.4-8

本版基于公开发布的 v3.20.4-3，包含以下改进：

- OpenAI Official Provider 支持逐模型设置上下文窗口，并按所选账号探测模型目录；明确区分官方公布默认值、账号目录默认值、可信可设置上限与 API 文档规格。GPT-6.1 Sol 在 ChatGPT Work 和 Codex 中的公布默认上下文为 500K，显式设置及账号目录限制仍优先生效。官方模型页列出的 API 上下文为 1.05M、最大输出为 128K；这些 API 规格不代表 Codex 账号目录上限，也不会自动把默认窗口扩大到 1M。1M 设置仍受可信目录上限门禁约束。
- 用量页将最近五分钟已记录的输入与输出速率分开显示。输入速率包含新输入、缓存写入和缓存读取 token；同一条用量只计一次。
- 修正 Codex 跨页续传会话的用量归并与恢复边界；只在验证过的前页边界内继承累计量，已入账的历史检查点不重放或补记费用，避免重复计费。
- 选择性适配官方 4.0.13 的流终止、工具语义等可靠性修复，保留 CCSM 自有路由、认证、数据库与协议边界。这不是完整的官方 4.0 架构迁移。

上下文来源：[OpenAI Help Center：ChatGPT Work and Codex](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex)、[OpenAI API：GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)。
