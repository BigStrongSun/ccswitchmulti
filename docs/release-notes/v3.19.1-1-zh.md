# CCSwitchMulti v3.19.1-1

这是 CCSwitchMulti 对上游 `cc-switch v3.19.1` 的本地跟进发布，版本号遵循
`v<上游版本>-<本地递增号>` 规则。

## 新增内容

- hosted `web_search` / `image_generation` 桥接，并支持 MultiRouter 工作台和
  设置向导中的 per-tool 开关。
- hosted tool 执行优先复用 Codex OAuth；显式配置独立 OpenAI API Key 时也可用。
- codex_oauth Responses SSE 上游在 HTTP 200 后中途断流时，代理侧最多重连 5 次，
  退避 200/400/800/1600/3200ms；仅在下游未收到实质内容前重试。
- codex_oauth 开启 thinking 时注入 `reasoning.summary:"auto"`，并在思考静默期
  每 10s 发一次 `ping`，避免 GPT-5.x 长思考被空闲计时器误杀。

## 修复内容

- 修复 Kimi K3 等 Chat 上游在 Codex MultiRouter 下含 hosted `web_search` 时
  “发消息后无回复”的问题：完整重放 Responses SSE 生命周期。
- 修复 `error decoding response body: unexpected EOF during chunk size line`
  被直接升级成整轮 502 的问题：对齐官方 Codex CLI `stream_max_retries=5`。

## 验证

- `streaming_retry` 17 个测试通过。
- `reasoning_summary`、`image_generation`、`hosted_tools` 相关测试通过。
- 已构建并安装 `3.19.1-1`，`127.0.0.1:15721` 健康检查通过。
