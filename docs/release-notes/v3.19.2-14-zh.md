# CCSwitchMulti v3.19.2-14

## 修复

- 模型目录明细调整为普通配置项，且显示在模型推理能力之前；它不再依赖“高级选项”是否展开。
- “自动发现”现在明确说明其依据是当前 Provider、模型和已验证的能力声明，且默认不写入模型配置。
- 自动发现到的能力可以一键复制为用户声明。复制后保留已确认档位与 `max -> Provider` 映射，用户可以编辑映射并单独开启 Codex Ultra。
- Ultra 继续作为 Codex V2 的“最大推理 + 主动 Sub-Agent 委派”模式；不会作为 Provider 原生档位或 literal `ultra` 发给第三方上游。

## 验证

- 模型目录、自动发现覆盖与 Ultra 开关的定向 Vitest 回归通过。
- `pnpm run typecheck`、格式检查与安装后桌面运行态验证见发布记录。
