# CCSwitchMulti v3.19.0-6

## 修复内容

- 修复 Codex 连接超时被误判为 `ResponsePending`：reqwest 连接阶段失败现在先按 `is_connect()` 归为 `ForwardFailed/502`，网络恢复后 Codex 的 `request_max_retries` 可以继续重试；只有确认请求可能在途的超时才返回 429。
- 增加 ResponsePending 30 秒 grace：常规超时后继续保留上游 future，上游迟到结果仍可正常交付，不再因为本地等待到期就把结果丢掉。
- 保留 reqwest/hyper 原始错误 source chain：`error sending request`、`error decoding response body` 等错误不再只剩最外层字符串，诊断能定位真实网络/body 阶段。
- 补充重连机制文档：覆盖 Auto Failover 关闭下的 Responses/Chat Completions 时序图与重连边界，文档位于 `docs/guides/codex-reconnect-mechanism-zh.md`。
- 保留 v3.19.0-5 已发布内容：Codex remote compact v2、SSE stream hint、安全的 pre-stream retry、MultiRouter 自环根修、账号池运行态、历史扫描 UI 修复和 hosted web_search 桥接。
