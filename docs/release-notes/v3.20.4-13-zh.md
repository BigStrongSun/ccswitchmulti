# CCSwitchMulti v3.20.4-13

修复 Codex Images API 与官方账号池的两处连续故障：

- Codex Desktop 内置 ImageGen 会直接发送 `gpt-image-2`。schema-v2 MultiRouter 现在会在这类图片模型不在文本模型目录中时，匹配到启用且目标为 OpenAI Official 的 Provider；显式图片路由、第三方图片路由和未知文本模型的既有边界保持不变。
- `POOL-001` 不再因为一次额度刷新失败而把旧额度快照永久当作新结果。额度尝试时间与成功观测时间已拆分，候选选择只使用新鲜额度；`reservePercent` 保留优先级语义，同时不会在仍有正额度时把整池误判为空。
- 额度选择仍保留官方 `allowed` / `limit_reached` 硬边界、凭据代际校验、重新登录要求和探测节流。

本版没有更改数据库 schema。安装新版后需要由新进程加载修复；已经留在旧进程内的账号池 soft-avoid 状态不会由源码提交自动清空。
