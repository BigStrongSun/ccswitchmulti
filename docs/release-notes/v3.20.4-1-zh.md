# CCSwitchMulti v3.20.4-1

本版以 CCSwitchMulti v3.20.2-22 为基线，选择性同步 CC Switch v3.20.4 中与现有 CCSM 架构兼容的代理和 Codex 认证修复；**不是**把原版代码整体合并到 CCSM，也不包含原版的 MiniMax Code 接入或数据库 v18→v19 迁移。

- Codex Responses 转 Chat 时，无描述工具不再发送 `description: null`；已存在的 `additional_tools` 提升和 `detail: original` 图像转换继续保留。
- Claude 工具转 Chat/Responses 时，同样省略缺失的工具描述，避免严格网关拒绝整轮请求。
- Claude `/effort max` 转 OpenAI 时，GPT-5.6 系列和 GPT-6 Astra 保留独立 `max` 档；旧模型仍回退 `xhigh`。GitHub Copilot 的 Chat 路径不再转发 auto mode 分类器不支持的 `stop` 参数，其它 Chat 上游继续保留该参数。
- 第三方 Codex Provider 的 API Key 仅存于数据库、live auth 为空时，编辑和切换回填不再擦除唯一凭据；live 新凭据与官方账号登出仍优先。
- OpenAI Official 固定绑定的 CCSM OAuth 账号被删除后，切换或开启代理接管会在改变当前卡片、备份或代理状态前拒绝失效 ID，并提示用户在编辑页显式选择新账号；不会悄悄换到其它账号。

边界：账号删除命令与切换锁尚未完全串行化；若删除恰好与已通过预检的切换并发，请求转发仍按绑定 ID 拒绝，不会自动使用别的账号。本版不声称已同步原版 v3.20.4 的全部功能、预设、UI 和修复。此前未完成的 Codex Desktop 控件直接验收也不因本次构建自动视为通过。
