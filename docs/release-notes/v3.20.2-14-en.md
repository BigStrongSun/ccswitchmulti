# CCSwitchMulti v3.20.2-14

Settings now has a "Watchdog and port self-check" panel so the supervisor state and the port occupancy evidence are visible without digging through logs.

## Added

- **Supervisor state**: enabled flag, current supervisor PID, and whether it is still running (red when not).
- **Auto restarts in the last 30 minutes**: taken from the watchdog restart budget record.
- **Local proxy port**: port, current listener PID, and readiness (marked as a problem when the listener is not this installed build).
- **Port occupancy diagnosis**: shown only when something is wrong, listing the PID, socket state and why an identity could not be read.
- **Recent events**: the latest eight watchdog log entries (`supervisor-started`, `supervisor-restarted`, `supervisor-clean-exit`, ...).
- The panel can be refreshed manually; it is backed by the read-only `get_watchdog_status` command and never changes runtime state.
