# CCSwitchMulti v3.20.2-10

本版把「代理端口被无法核验的进程占用」从一次性、需要人工介入的失败，改造成可诊断、可自愈的恢复流程，并包含此前 main 上的协议探测与 Provider 修复。

## 端口占用诊断与自动恢复

- 端口绑定失败时不再只说“监听进程身份无法完整验证”：现在会同步读取 IPv4/IPv6 的**全部** TCP 状态，记录每个占用者的 PID、状态（LISTEN/TIME_WAIT/…）以及可读的进程路径，或读不到身份时的确切原因（进程不存在 / 拒绝访问 / 其它 Win32 错误）。
- 启动恢复遇到端口占用时不再立即清除接管状态：会登记一个有期限的接管意图（默认 15 分钟），由 5 秒监听守护在端口释放后自动完成接管，成功后再通知界面收起旧的失败提示。
- 仍然 fail-closed：无法核验的进程不会被结束或接管；用户手动“解除占用并恢复接管”时也能看到 PID 与失败原因。
- 顺带修复 Provider 切换路径中 6 条 UTF-8→GBK 双重编码的乱码错误文案。

## 协议与 Provider 修复

- 保留用户手写的协议覆盖，并在保存前恢复有效的探测证据。
- 该修复只作用于本地路由与协议探测，不改变已接管配置的既有语义。
