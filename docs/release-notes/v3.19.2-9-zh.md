# CCSwitchMulti v3.19.2-9

本版本为 v3.19.2-8 的兼容性修复版本，重点修复 Qwen/vLLM 非流式请求的 Chat → Responses 转换错误。

## 修复

- 修复 vLLM/OpenAI-compatible 非流式响应中 `function_call: null` 被误判为 legacy function call，导致 `stream=false` 返回 HTTP 422 的问题。
- 保留真正未命名 tool/function call 的错误校验，避免把畸形工具调用静默转成成功响应。

## 推理能力配置

- 保留逐模型的 Codex 推理能力手动声明入口，允许不同 Qwen/vLLM 部署按实际参数契约配置原生档位、默认值和映射。

- 前端 reasoning capability 测试：4 passed。
