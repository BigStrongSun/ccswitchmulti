# CCSwitchMulti v3.19.2-6

## Codex 子 Agent 跨 provider 明文投递（第三方中转父模型）

- 修复第三方中转父模型（如 Longnows，背后是官方 backend）→ 第三方子模型的 V2 加密任务失败：此前 Stage A 只在父出站为官方 OAuth 原生透传时剥离 `message.encrypted`，第三方中转父模型不剥离，导致中转背后的官方 backend 按 schema 把 `message` 加密成 Fernet 密文，子 Agent 收到不可解密的 `agent_message` 被 Stage B 拒绝。
- 现在只要 MultiRouter 含启用的第三方/来源歧义路由，无论父出站是官方 OAuth 还是第三方中转，都剥离非保留 `agents.spawn_agent/send_message/followup_task` 的 `message.encrypted`；纯官方 Router 与非 Router provider 行为不变。

## Codex Responses→Chat commentary 与工具调用合并

- 修复同一次 Codex Responses 输出中的 commentary `message` 与随后的 `function_call` 被转成两条连续 assistant 历史消息的问题；Qwen/vLLM 因此不再反复看到“纯进度 assistant → 下一条才调用工具”的错误示范，减少“只播报进度就 stop”的短轮。
- 跨 item 重复的 `reasoning_content` 去重，工具输出与媒体边界保持原语义。

## Codex 模型选择器用户自定义顺序

- 合入用户 PR #18：Codex 模型选择器支持用户自定义排序（`sort_index`），自定义顺序在目录刷新后保留。

## CI 恢复绿灯

- 从根因修复 main 分支 28 个 Clippy lint、unix 平台死导入与 macOS 测试夹具，CI 三平台矩阵恢复全绿。

完整测试验证：Rust library（3109 passed，0 failed，5 ignored）、`cargo fmt --check` 与 `git diff --check` 均通过。
