# CCSwitchMulti v3.20.2-5

This is the first formal release after `v3.20.2-3`, bundling Codex status/repair observability, OpenAI Official Provider authentication ownership, bounded Codex capacity auto-resume, DeepSeek/GLM reasoning projection, and Moonshot MFJS compatibility fixes. Database schema remains v22.

## Codex Status & Repair

- Refresh progress is no longer just a stage name: closing processes, waiting for exit, paginated-history scan/migration/per-file repair, config reprojection, launch, and verification emit concrete log entries.
- Long operations emit a heartbeat every 2 seconds. The UI shows a repair progress log, last activity time, and elapsed time for the current stage.
- Paginated-history repair has a 15-minute hard timeout, so a stuck file/SQLite operation no longer leaves the command pending forever.
- The frontend has a 30-second event-silence watchdog. A silent backend now fails visibly instead of continuing to show "refreshing".
- Each refresh run has its own run id, so a late backend result cannot overwrite a stall failure.

## OpenAI Official Provider Authentication

- The Official Provider is now the single source of truth for official authentication: choose Desktop native login, a fixed CCSM OAuth account, or an OAuth account pool inside the Provider. MultiRouter only consumes the resolved auth policy and no longer owns a parallel OAuth configuration.
- Direct Official routes keep working with a fixed OAuth account or account pool when MultiRouter is disabled. Legacy schema-v2 Router authentication migrates when the source is unambiguous and fails closed when it is ambiguous.
- Raw forwarding now resolves a unique route per endpoint, records request-local hit/miss, expands the account pool only for the matched Official route, and then forwards. Unknown non-text endpoints no longer inherit the text fallback.
- Direct Official pool candidates keep canonical `codex-official` attribution, so status, health, failover, hot-switch, and current-provider state do not create fake routes.

## Other Fixes

- Codex capacity responses support bounded auto-resume, with the database v22 migration ordering fixed for related seed writes.
- Codex's latest `automation_update` root union with a `$ref` to a nested `oneOf` is projected before MFJS compilation, eliminating the local 422.
- DeepSeek/GLM reasoning projection and catalog metadata fixes prevent first-request 400s or raw reasoning loss.
- Release verification covers the full frontend and Rust suites, TypeScript, Prettier, rustfmt, and cargo check. Database schema remains v22.
