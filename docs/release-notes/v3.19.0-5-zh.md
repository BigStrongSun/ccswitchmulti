# CCSwitchMulti v3.19.0-5

## 修复内容

- 补齐 Codex remote compaction v2：检测 `responses_compaction_v2` 或 `/responses + compaction_trigger`，原生 Responses route 保持 `/v1/responses` 并合成唯一 `ocx1:` compaction item，Chat route 同步适配；后续请求会把 `ocx1:` 还原为可读摘要，避免 Codex 报 `expected exactly one compaction output item`。
- 修复未标记 SSE 被当 JSON 缓冲的问题：Codex Responses 请求按请求 `stream` 标志判断流式响应，官方 SSE 即使没有 `text/event-stream` content-type 也不会再被整体缓冲后误报 502。
- 恢复安全的 Codex pre-stream 重试：`request_max_retries` 恢复到 2，允许连接建立前/HTTP 5xx 安全重试；保持 `stream_max_retries=0`，并在响应体已读阶段继续用 `ResponsePending/429` 防止在途请求被整轮重发。
- 保留 v3.19.0-4 已发布的 MultiRouter 自环根修、账号池运行态、超时重发放大修复、历史扫描 UI 修复、MSI ICE38 修复和 hosted web_search 桥接。
