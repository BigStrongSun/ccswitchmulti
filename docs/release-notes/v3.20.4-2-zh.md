# CCSwitchMulti v3.20.4-2（本地候选）

本版基于 v3.20.4-1，修复 Codex 经 CCSM 代理调用新模型时可能因 `version` 请求头被上游拒绝的问题。此文档不表示已发布、已安装或已完成真实账号端到端验收。

- 官方 Codex 上游继续保留可信客户端的 `originator` 和 `User-Agent`，但不再从 User-Agent 推导出请求中原本不存在的独立 `version` 头；旧配置或外部请求的 `version` 也不会透传。
- 第三方 Codex Responses 上游默认不继承客户端 `version` 指纹；Provider 若确实需要它，仍可通过明确的请求头覆盖设置自己的值。
- Codex raw/WebSocket 共用的透传头构造同样剥离客户端原始 `version`，避免非 JSON 请求漏掉这一身份边界。
- Codex 转 Anthropic Messages 时也过滤客户端独立 `version` 指纹，但保留协议所需的 `anthropic-version`。

MiniMax Code 仍未接入。本版仅修请求头兼容性；上游的 MiniMax Code 是完整受管应用，涉及配置、MCP、Skills、会话、用量和数据库迁移，不能作为此修复的附带变更。
