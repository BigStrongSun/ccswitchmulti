# CCSwitchMulti v3.20.2-9

本版本修复 Codex Desktop 对第三方模型 reasoning 过程不显示的问题，并把自动转换与协议探测结果完整绑定。

## Codex Desktop reasoning 映射

- 可信本机 `Codex Desktop` 请求自动启用适配，无需额外 UI 开关。
- Chat 路径根据已验证的 Chat 探测 profile 投影 `reasoning_content`、`reasoning`、`reasoning_details` 和 think-tag 等可读 raw reasoning。
- 原生 Responses 路径根据最终 provider、公开模型和上游模型对应的 Responses 探测 profile，将 `response.reasoning_text.delta/done` 映射为 Desktop 可显示的 summary 生命周期。
- 只有当前版本、未过期、`Verified`、`selected_transport=open_ai_responses` 且 reasoning 形状为 readable raw source 时才映射；已有 summary、opaque、无探测或探测失败均保持原样。
- 当上游先发送 reasoning delta、缺少 `response.output_item.added` 时，自动补齐 reasoning item 和 summary part 生命周期。

## 兼容性与安全边界

- CLI、TUI、External API、非 Desktop 请求继续保留原始 reasoning 语义。
- 不按 DeepSeek、GLM 或 hostname 写死，模型差异由协议探测 profile 决定。
- 当前运行中的旧 CCSM 进程不在本次源码 release 操作中被终止或替换。
