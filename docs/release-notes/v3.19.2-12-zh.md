# CCSwitchMulti v3.19.2-12

这是一次第三方 hosted tool 流式兼容性修复版本。

## 修复

- 修复同一条流式 Chat 回合同时出现 CCSwitchMulti hosted tool（例如 `web_search`
  ）和普通 function tool 时，代理直接返回
  `Mixed hosted and ordinary function tool calls are not supported in one streaming turn`
  的问题。
- hosted tool 继续由 CCSwitchMulti 执行，普通 function tool 的
  `response.function_call_arguments.*` 事件继续交给 Codex，二者完成后续接同一条
  Responses 流，不再把有效的并行调用判定为错误。
- 保留 hosted tool 未被上游调用时的脱敏诊断，不伪造模型调用。
