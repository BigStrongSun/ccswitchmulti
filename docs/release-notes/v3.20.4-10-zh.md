# CCSwitchMulti v3.20.4-10

本版重点改进 Codex 官方模型目录和不同模型服务商的模型元数据发现：

- 扩展模型列表解析，适配 OpenAI-compatible `data[]`、Google `models[]`、阿里云百炼/Qwen `output.models[]` 及其分页、嵌套模型限制与输入输出模态字段。
- 读取 DeepSeek 官方模型列表中的上下文窗口、输出上限、模态和推理强度；支持 vLLM 的 `max_model_len` 及 Strata/llama.cpp 的 `meta.n_ctx`。
- GLM 列表缺少上下文长度或最大输出上限时，从智谱官方模型文档补齐；只补缺失值，不覆盖接口显式值。未提供可信正整数的字段保持未知；输入 Token 上限不会误报为总上下文窗口。
- Codex 官方模型设置支持查看本次发现的模型并快捷筛选要启用的模型，同时保留手动上下文覆盖。

跨平台安装包、签名及自动更新清单由 GitHub Release workflow 构建和验收；具体平台覆盖以发布产物为准。
