# CCSwitchMulti v3.20.4-9

本版基于 v3.20.4-8，重点改进 Codex 官方模型目录与代理请求的可靠性：

- 修复 Codex 官方模型目录刷新、持久化和配置投影的边界问题。刷新目录不再占用配置接管锁；仅在 CCSM 拥有本地 Codex 配置时自动投影默认模型，切换官方认证方式时保留已发现的目录。
- 修复 Codex 桌面登录态下的图像生成路由，并在外部 OpenAI 兼容 API 选择 Codex Router 时，按请求模型解析路由及对应协议。
- 明确 Codex 客户端与代理的传输重试所有权，避免代理和 Codex 对同一请求叠加重试；为本地传输失败提供稳定的来源标识，同时保留上游 HTTP 错误原貌。
- 修复官方目录保存、设置向导错误反馈和图像路由相关回归，并改进 CI 对文档变更与完整代码变更的检查调度。

本版的跨平台安装包、签名及自动更新清单由 GitHub Release workflow 构建和验收；具体平台覆盖以发布产物为准。
