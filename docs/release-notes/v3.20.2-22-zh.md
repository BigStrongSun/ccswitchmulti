# CCSwitchMulti v3.20.2-22

本版修复 Codex 官方模型目录自动刷新后，CCSM 生成目录未同步更新的问题。公共快照的模型能力内容变化时，CCSM 在网络刷新预算之外重新投影自己管理的模型目录和缓存；投影会使用 Codex 接管切换锁，并复核当前接管状态、Router 和目录所有权，不覆盖用户自管目录。

本地 Windows 构建与安装态已验证：已安装主程序为 3.20.2-22、哈希与构建产物一致，代理健康检查返回 200。使用当前 Codex 二进制启动独立诊断 app-server，`model/list` 返回 GPT-6 Sol/Luna 的完整推理档位及 Fast 元数据。

已知边界：运行中的 Codex app-server 对静态 `model_catalog_json` 可能保留启动时快照。上述独立诊断不等于当前桌面窗口的控件验收；自动刷新成功到桌面 UI 的端到端验证仍未完成。本版不自动重启 Codex。Windows 卸载注册表的旧 `DisplayVersion` 与已安装文件版本不一致，后续需独立排查。
