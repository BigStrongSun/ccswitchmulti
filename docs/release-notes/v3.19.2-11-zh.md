# CCSwitchMulti v3.19.2-11

这是一次 hosted tool OAuth 协议兼容性修复版本。

## 修复

- 修复第三方模型调用官方 hosted `web_search` 时，ChatGPT Codex OAuth 后端返回 `400 Input must be a list` 的问题。
- OAuth hosted web search 和 image generation 请求改用 Responses 输入数组，并按 Codex OAuth 后端要求使用 SSE。
- OAuth SSE 响应复用 CCSM Responses 聚合器，搜索结果和图片结果可以继续回填给第三方模型。
- 上游返回结构化 `detail` 错误时，日志和模型工具结果会显示具体协议原因，不再只显示笼统的 400。

## 验证

- Rust 全量库测试：3262 passed / 0 failed / 5 ignored。
- hosted tool 定向测试：26 passed。
- 真实 Codex OAuth hosted web search：HTTP 200，收到 `response.web_search_call.completed` 和 `response.completed`。
- 发布后还需通过第三方 Qwen canary 验证代理、第三方模型和官方 OAuth hosted search 的完整链路。
