## Delivered scope

- Migrated the audited upstream 3.20.2 reliability changes and the Trace transport error-chain, bounded-body and UI-state corrections.
- Added fail-closed pagination-history preflight across Provider migration, restore, visibility repair and direct-write paths.
- Added evidence-bound recovery for historical Provider migration damage: only Provider-field differences are accepted; SQLite cursor/reference updates use transactional compare-and-swap, JSONL length and mtime are preserved, and failure rolls back.
- Corrected fork lineage validation so active-segment identity is authoritative while ancestor `history_base` offsets must still land on complete record boundaries.
- Kept Codex's duplicate-ordinal allocator defect outside CCSM. This release does not modify or deploy Codex and does not automatically repair real user history.
- Made local release builds use one repository-owned isolated Cargo target and clean it after export. The final fix prevents Windows PowerShell 5.1 from promoting Cargo's normal stderr progress into a false cleanup failure while still rejecting a real nonzero Cargo exit code.
