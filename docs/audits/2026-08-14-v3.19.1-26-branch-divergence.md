## Intentional experiment / NO-GO 详细证据

### Portable reasoning summary 实验

- 相关 ref：`refs/heads/bigstrongsun/portable-reasoning-experiment-nogo`。
- isolated DeepSeek native Responses 阶段能实时生成 reasoning，但同一 task 切回 built-in OpenAI direct continuation 后，官方 backend 返回 404，指出合成的 `rs_ccswitch_*` item 在 `store=false` 下不存在。
- 这证明失败边界不是本地显示，而是伪造 reasoning ID 被官方解释为 server-side item reference。实验按 stop condition 停止；未 compaction、未继续切回 DeepSeek、未补兼容 patch。
- 分类：`intentional-experiment/no-go`；禁止把该状态机、codec 或分支整树移入 release。

### Assistant commentary 实验

- 相关 ref：`refs/heads/bigstrongsun/commentary-reasoning-experiment`。
- 固定 Codex 在完全隔离的 HTTP/WebSocket loopback pre-gate 中，去除本地 commentary ID 后，官方 direct continuation 仍返回 HTTP 400 `Invalid request payload`；隔离 CCSM 代理日志保持零，证明失败在官方路径而非 CCSM 转发。
- 按批准的 stop condition，没有继续 DeepSeek live reasoning/tool canary、官方同任务 continuation、reverse heuristic、compaction 或其它 message-shape workaround。
- 分类：`intentional-experiment/no-go`；任何未来重启必须新设计、新静态评审和独立 live gate，不能“先合并再试”。

## 不确定性、非阻断 follow-up 与 release 门禁

1. 无共同祖先的 refs 无合法 `git cherry ... MERGE_BASE` limit，因此 unique count 保持 N/A；直接 tree diff 不能替代可移植性审计。
2. 本轮没有执行 fetch，但已在 2026-08-15 用 live `git ls-remote --heads fork` 将服务器端 138 个 heads 与本地排除 symbolic HEAD 后的 138 个 tracking tips 逐 SHA 比较，结果 `NEW/MOVED/DELETED=0`。该证明只覆盖检查时刻；后续发布前若远端再次变动，应重新运行 live tip 对比并对新增对象独立审计。
3. NO-GO 真实请求证据来自既有隔离实验记录；本轮没有重放 404/400 live gate。
4. 当前 `actionable-missing=0`。原四项非阻断后续中两项已经由 final fix wave 收口：initializer 测试现在证明 API 实际返回的 persisted-provider identity，Sessions 注释也已改为显式调用方的独立历史修复。仍保留两项条件性风险：Task 9A 前端 catalog identity 的 `localeCompare` 尚未与后端 NFKC + case-fold 对齐；Sub-Agent V2 reasoning preset 尚未把模型 catalog 支持集合和默认值作为端到端单一契约。它们没有对应未移植 runtime patch，不改变历史分叉 `actionable-missing=0` 的结论；本机安装态差异由 Task 11 的事务安装与运行验收处理，不再混入功能分叉分类。
5. Rust 冷编译/全量门禁在 Windows 上固定 `CARGO_BUILD_JOBS=2`、`--test-threads=1`，避免并行任务之间争抢构建资源；这是 release baseline，不应被改写为默认无限并发。
6. 审计 HEAD 之后的发布脚本与依赖兼容修复不来自任何历史功能分支，不改变 173-ref/198-patch 分类。特别是 `6a513c08` / `82a4e7c1` 处理本地 Tauri CLI 与 Cargo `tauri-utils` 的 bundle metadata 协议错位，属于 Task 11 构建门禁现场发现，不是新的 `actionable-missing` 历史 patch。
