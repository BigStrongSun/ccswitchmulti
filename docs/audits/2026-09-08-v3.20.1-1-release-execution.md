### Gate findings

- The first full frontend run at `a908c389` failed 1 of 1537 tests: the OpenCode PPIO preset exposed Tencent Token Plan models instead of its own DeepSeek V4 Flash model.
- Root cause: `1a905f16` inserted the Tencent OpenCode presets but also replaced the adjacent pre-existing PPIO `settingsConfig.models` object with a duplicate of the Tencent personal-plan catalogue. This was source-data contamination, not a shared-object runtime mutation.
- The existing PPIO assertion supplied the RED evidence. Restoring only the PPIO model object made the combined PPIO/Tencent focused suites pass 31/31. The full frontend item remains unchecked until it is rerun against the repaired candidate.
- The repaired candidate `110da36f` passed the full frontend suite: 185/185 files and 1537/1537 tests.
- The first parallel Rust full run compiled successfully, then passed 4045 tests, ignored 6 and failed 2. The Codex config CAS test passed alone, identifying process-wide test-home/settings interference between parallel tests rather than a product CAS failure. The final Rust suite will therefore use one test thread while Cargo compilation remains parallel.
- The other Rust failure was deterministic: `b30b470d` changed the Grok 4.5 cache-read seed from 0.50 to 0.30 but the historical backfill assertion still expected the old amount. Its existing RED now passes with cache cost `0.000075` and total cost `0.001575`.
- After the Grok expectation was corrected in `6b22a8d9`, the final serialized Rust library run passed 4047 tests, failed 0 and ignored 6. The integration binaries also passed in full: app_config_load 4/4, app_type_parse 2/2, deeplink_import 2/2, hermes_roundtrip 2/2, import_export_sync 26/26, mcp_commands 23/23, profile_roundtrip 8/8, provider_commands 10/10, provider_service 36/36, proxy_commands 2/2, skill_sync 7/7 and support_safety 3/3.
- The frontend full suite is not repeated after the Rust-only assertion correction. Remaining Task 12 checks are static analysis, renderer/sidecar/Tauri build and artifact validation.
- TypeScript, Prettier, `cargo check --all-targets`, rustfmt, diff and the renderer production build passed. The renderer emitted only the repository's existing stale browser-data, mixed static/dynamic import and large-chunk warnings.
- An exploratory stricter `cargo clippy --all-targets -- -D warnings` exposed 30 Rust 1.95 lints: 2 in production code and 28 in historical test code. The repository CI runs default-target Clippy, not all-targets. The two production findings were corrected with semantics-preserving standard-library forms (`contains` and `then_some`); the related provider-contract test passed 1/1 and the exact CI Clippy command then passed. The 28 test-only style findings are not hidden with `allow` attributes and are not folded into this release as an unrelated cross-module cleanup.
