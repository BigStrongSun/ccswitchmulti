## 阅读方式

直接通过本地 HTTP 服务打开 `index.html`。支持：

- `←` / `→`：翻页；
- `O`：页面总览；
- `T`：切换 `engineering-whiteprint`、`academic-paper`、`tokyo-night` 主题；
- 橙色虚线术语：悬停/聚焦显示解释，点击固定，`Esc` 关闭；
- 架构页“深入源码”入口：打开对应配置、源码与请求剖面，`Esc` 返回原页；
- `#/页码`：深链到指定页面。

课件从 html-ppt `document-deck` 模板派生，运行时、字体、主题与动画样式已经复制到本目录 `assets/`，可离线托管。页面正文不依赖 presenter notes。

## 内容边界

课件解释 Codex V1/V2、custom role、第三方模型障碍、CCSM 控制面/数据面、新角色运行链和 V23 配置事故。它不是安装运维手册，也不声称 CCSM 可以解密 OpenAI ciphertext，或将 role description 当作确定性模型路由。
