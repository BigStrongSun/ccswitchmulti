## Confirmed Source Findings

- Upstream 4.0.13 defaults aggregation to classic V1 tools as a workaround for V2 ciphertext crossing providers. Explicit `multi_agent_v2` can override the default; upstream is not V1-only.
- `[agents].default_subagent_model` and `default_subagent_reasoning_effort` are independent configuration defaults. Upstream validates them against the merged catalog; do not replace this machinery with CCSM role profiles.
- Official issue discussions #8253 and #8286 support these distinctions. Built-in Web and fetched official source were checked; the independent Matrix search returned `fetch failed`, not a negative search result.
- The official default parent's model is unprefixed and can spawn prefixed third-party Stack children. Current provider classification / `is_stack` alone cannot decide whether parent task encryption must be disabled.
- Reserved `collaboration.*` schemas must remain unchanged. Only non-reserved `agents.*` schema markers are eligible. Real opaque tasks cannot be decrypted, dropped, or replaced with placeholder success.
- Existing upstream opaque-state rectifier behavior must remain unchanged outside the explicit managed V2 path. Synthetic HTTP fixtures are not native Codex or production E2E proof.
